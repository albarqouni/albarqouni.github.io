abstract: Giant Cell Arteritis (GCA) is a serious autoimmune disease that affects large and medium-size arteries, potentially leading to severe complications like vision loss if not diagnosed promptly. Current diagnostic methods rely heavily on clinical judgment and ultrasound imaging techniques, which require experience and expertise. This work investigates the use of supervised deep learning to improve the detection of hypoechoic wall thickening in ultrasound images, a key indicator of GCA. We developed an affordable and efficient artery-fusion deep learning model that receives an ultrasound image as input and considers artery type to enhance the detection accuracy.
